视觉 Transformer 模型，核心原理可以概括成一句话：

**把图像像“句子”一样切成一串 token，再用 Transformer 的自注意力机制去建模这些 token 之间的全局关系。**

你可以把它分成 5 个关键步骤来理解。

## 1. 先把图片切成小块

传统 CNN 是用卷积核在图像上滑动，逐步提取局部特征。
 而 Vision Transformer（ViT）通常会先把一张图像分成很多固定大小的小块，比如：

- 输入图像：`224 × 224`
- patch 大小：`16 × 16`

那么就会得到：

- `14 × 14 = 196` 个 patch

每个 patch 就像 NLP 里的一个“词”。

也就是说，**图像不再直接作为二维像素阵列处理，而是被拆成一个 patch 序列**。

------

## 2. 把每个 patch 变成向量

每个 patch 本质上还是一小块像素值，不能直接送进 Transformer。
 所以要先把它“展平”并映射成一个固定维度的向量，这一步叫：

**Patch Embedding**

例如：

- 一个 `16 × 16 × 3` 的 patch
- 展平成一个长向量
- 再通过线性层投影到 `D` 维特征空间

这样每个 patch 都变成一个 token embedding。

------

## 3. 加上位置信息

Transformer 本身并不知道 token 的空间位置。
 但图像里“左上角”和“右下角”的 patch 显然意义不同，所以必须告诉模型每个 patch 在哪里。

这就要加入：

**Position Embedding（位置编码）**

于是每个输入 token 变成：

**patch 特征 + 位置信息**

这样模型就知道：

- 哪些 patch 在上面
- 哪些 patch 在下面
- 哪些 patch 相邻
- 哪些 patch 相隔很远

------

## 4. 用自注意力建模全局关系

这一步是视觉 Transformer 最核心的地方。

Transformer 的自注意力机制会让每个 patch 都去看所有其他 patch，并学习：

- 哪些区域和自己有关
- 应该关注哪些位置
- 全局上哪些部分一起决定当前语义

比如识别一只猫时：

- 一个 patch 可能看到“耳朵”
- 另一个 patch 可能看到“眼睛”
- 还有 patch 看到“身体轮廓”

自注意力可以把这些远距离的信息直接关联起来。
 所以相比 CNN 更强调局部感受野，Transformer 更擅长：

**建模长距离依赖和全局上下文。**

------

## 5. 输出分类或其他视觉任务结果

在最经典的 ViT 里，通常会在 patch 序列前面加一个特殊 token，叫：

**[CLS] token**

经过多层 Transformer 编码后，这个 token 会聚合整张图的信息，最后用于：

- 图像分类
- 检测
- 分割
- 跟文本联合建模等任务

------

# 它和 CNN 的本质区别

你可以这样记：

### CNN

- 强归纳偏置很强
- 天然适合局部模式提取
- 平移不变性更强
- 更容易在小数据集上训练

### Vision Transformer

- 归纳偏置更弱
- 更依赖大数据训练
- 更擅长全局关系建模
- 可扩展性强，容易和语言模型统一

所以早期 ViT 的一个特点就是：

**数据不够大时不一定比 CNN 强，但在大规模预训练下性能非常强。**

------

# 视觉 Transformer 的公式层面怎么理解

设图像被切成 $N$ 个 patch，每个 patch 映射成 $D$ 维向量：
$$
z_0 = [x_{class}; x_p^1E; x_p^2E; \dots; x_p^NE] + E_{pos}
$$
这里：

- $x_p^i$：第 i 个 patch
- $E$：线性投影矩阵
- $E_{pos}$：位置编码
- $x_{class}$：分类 token

然后送入多层 Transformer Encoder：
$$
z'_l = MSA(LN(z_{l-1})) + z_{l-1}
$$
其中：

- `MSA`：多头自注意力
- `LN`：LayerNorm
- `MLP`：前馈网络
- `+`：残差连接

最后用分类头输出结果。

------

# 为什么它有效

因为图像理解本质上也需要“关系建模”。

比如识别“人在骑自行车”时，不只是看某个局部纹理，而是要理解：

- 人的位置
- 车轮的位置
- 人和车之间的相对关系

Transformer 的自注意力机制很适合做这种全局关联。

------

# 它的主要优缺点

## 优点

- 全局建模能力强
- 易于扩展到大模型
- 容易和文本、动作、语音等统一到一个架构里
- 在多模态任务里非常常见

## 缺点

- 计算复杂度高，自注意力通常是 $O(N^2)$
- 对数据量要求更高
- 小样本场景下未必优于 CNN
- 高分辨率图像时 token 太多，开销大

------

# 常见改进方向

后来很多视觉 Transformer 都是在解决它“计算太贵”的问题，比如：

- **Swin Transformer**：用窗口注意力降低计算量
- **DeiT**：改进训练策略，让 ViT 在较小数据集上也能训好
- **PVT**：做分层结构，适合检测和分割
- **Masked Autoencoder (MAE)**：做自监督预训练

------

# 一句话总结

视觉 Transformer 的主要原理就是：

**把图像切成 patch 序列，给每个 patch 做向量化和位置编码，再通过 Transformer 的自注意力机制学习全局视觉表示。**
