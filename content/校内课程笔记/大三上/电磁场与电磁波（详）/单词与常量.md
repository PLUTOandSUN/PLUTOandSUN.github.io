## 常用常量
| **物理量/组合** | **符号**                                                       | **便于计算的近似值**                                                    |
| ---------- | ------------------------------------------------------------ | --------------------------------------------------------------- |
| **库仑常数**   | $k_e = \frac{1}{4\pi\varepsilon_0}$                          | **$9 \times 10^9$**                                             |
| **真空介电常数** | $\varepsilon_0$                                              | **$\frac{1}{36\pi} \times 10^{-9}$** (约 $8.85 \times 10^{-12}$) |
| **真空磁导率**  | $\mu_0$                                                      | **$4\pi \times 10^{-7}$**                                       |
| **真空阻抗**   | $Z_0 = \sqrt{\frac{\mu_0}{\varepsilon_0}}$                   | **$120\pi$** 或 **$377 \Omega$**                                 |
| **光速**     | $v_{p, freespace} = \frac{1}{\sqrt{\mu_0 \varepsilon_0}} =c$ | **$3 \times 10^8 \text{ m/s}$**                                 |
