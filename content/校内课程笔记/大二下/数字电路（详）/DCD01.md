# **1 Number Systems**
## **1.1 位权制（Positional Number System）：**
在位置数字系统中，每个数字都由一串数字表示。
每个数字的位置都有相应的权重。 数字的值等于所有数字的加权和，权重由数字的位置和数字系统的基数（或弧度）决定。
|**关键词**|**含义**|
|---|---|
|**基数／进制 (base, radix)**|一共有多少个不同的**数字符号**可用。十进制是 10 个（0–9），二进制是 2 个（0、1）……|
|**位权 (weight)**|某一位上的数字要乘上的幂次：|
|- 个位 → 基数^0||
|- 十位 → 基数^1||
|- 百位 → 基数^2 …||
|**数值计算**|把“各位数字 × 该位权”相加即可得到实际大小。|
**以十进制示例：**
|   |   |
|---|---|
||321₁₀ = 3 × 10² + 2 × 10¹ + 1 × 10⁰|
||= 300 + 20 + 1|

## **1.2 最高有效位 (Most Significant Bit / Digit, MSB) 和 最低有效位 (Least Significant Bit / Digit, LSB)**
|**名称**|**位置**|**权值（以 110101₂ 为例）**|**对结果的影响**|**常见用途**|
|---|---|---|---|---|
|**MSB**  <br>最高有效位|**最左边**那一位|2⁵ = 32|决定数值的“量级”——如果把 MSB 从 1 改成 0，数就少 32|· 补码表示的符号位  <br>· 比较器首先查看 MSB 判断大小  <br>· 移位时，左移 k 位相当于把 LSB 清掉、MSB 空出 k 位|
|**LSB**  <br>最低有效位|**最右边**那一位|2⁰ = 1|只影响 ±1 的精细变化|· 奇偶检测 (x & 1)  <br>· 加法器从 LSB 开始传播进位  <br>· 某些串行协议要约定“先传 LSB 还是先传 MSB”|

## **1.4 十进制到任何基数**
**反复除基取余**（Repeated Division – Remainder）:
1.**余数先出 LSB**：
队列式写下余数，从上到下其实就是 **低位 → 高位**；最后倒着读才是完整结果 110101₂。
2.**商为 0 停止**：
不少初学者会再多除一次，把 0 也写进“余数列”；记住商一旦变 0 就收工。
3.**权值验算**：
右侧的加权和检查，能快速发现漏写/抄错位的问题——建议考试时都写一下。

## **1.5 从小数（非整数）到任何基数**
整数部分用上述的**反复除基取余**来计算
小数部分如下：
原数的小数部分 f0（0 ≤ f0 < 1），乘以基数 R。
记录乘积的 **整数部分** d1 作为新的一位（从 **小数的最高位** 开始）。
再取乘积的小数部分 f1，重复 “乘 R 取整” 步骤。
按生成顺序把各 di 顺接，就是小数在 R 进制下的表示；通常遇到无限循环就截断保留若干位。

# **3 负数和浮点数**
## **3.1 负数**
表示负数有两种方法：
- Sign-Magnitude Representation **符号-幅度表示法**
- Two’s Complement **二补数法**
### **3.1.1符号幅度法：**
**十进制**：在前面加+和-；
**二进制**：MSB位置1或者0。
### **3.1.2 二补数法：**
- 对于 n 位二进制，共有 2n 种不同的位模式。
- 二补数把它们分成两部分：
    - **正半区**（包括零）：从 0…0 到 0…11…1，即十进制的 0 到 2n−1−1。
    - **负半区**：从 1…00…0 到 1…11…1，对应十进制的 −2n−1 到 -1。
对于 4 位来说，范围就是 [−23,23−1]=[−8,7]。
### **3.1.3 二补数转换规则：**
1. **正数**：和无符号二进制完全相同，直接写出 n 位二进制并在高位补 0。
2. **负数**：
    1. 先将该数的绝对值用 n 位二进制表示。
    2. 对这 n 位二进制逐位取反（0→1，1→0）。
    3. 在取反结果上加 1（即最低位做加一，遇到进位就继续向左进位）。
这样得到的就是该负数的二补数表示。
### **3.1.4 符号扩展**
当我们把一个 n 位的二补数数值，转换到更多位（比如从 8 位扩到 16 位）时，不能简单地在高位都补 0（那样会改变负数的值）。正确的做法是：

> 复制原来最高位（符号位）到所有新增的高位。
- 如果符号位是 **0**（表示正数），就把新增的位都补 0。
- 如果符号位是 **1**（表示负数），就把新增的位都补 1。

- 正数：同无符号二进制；负数：对绝对值取反再加 1。
- **运算统一**：加法／减法都当作“加法”处理（减法变成加上二补数负数），硬件只需一个加法器。

### **3.1.6 溢出**
**定义**：当两个 n 位数相加或相减后，结果在数学上超出了 [–2(n–1),2(n–1)–1] 的范围，就会“跑出”这 n 位能表达的空间。
**表现**：
- 最高位的进位被丢弃 → 结果符号错；
- 或简单地丢失最左边的那一位 → 数值完全不对。
**如何避免溢出？**
1. **约束输入范围**
    - 设计时确保所有可能的输入和中间结果都落在可表示的范围内。
2. **增加位宽**
    - 如果结果可能超出当前位宽，就要用更多位来存储（e.g. 8→16 位）。
3. **舍弃低位（LSB Truncation）**
    - 当只缺少几个最低有效位时，舍弃它们可保留高位范围，但精度会下降；千万不要舍弃最高位（MSB），否则会导致巨大错误。

# **4 Binary, Decimal, Alphanumeric 二进制，十进制和字母数字**
## **4.1 二进制编码 Binary Codes**
**Code**：是一个由 n 位二进制字符串组成的集合，每个不同的字符串表示不同的数值或信息（比如颜色、状态、符号等）
N 位可表示的**无符号十进制值**范围是从 0 到 2N–1
## **4.2 Binary Coded Decimal (BCD) 二进制转十进制**
即一个十进制数字用四个二进制数字表示
## **4.3 Alphanumeric 字母数字**
### **4.3.1 ASCII Code**
ASCII（美国信息交换标准代码）是一种 **7位二进制编码**，可以表示 27=1282^7 = 12827=128 个不同的字符。
包括以下内容：
- **大写英文字母**（A–Z）
- **小写英文字母**（a–z）
- **数字**（0–9）
- **标点符号和部分特殊符号**（如 $, &）
示例编码：
'A' = 01000001₂ = 41₁₆（16进制）
'&' = 00100110₂ = 26₁₆
**为什么使用8位存储**：
或用于**奇偶校验**（一种简单的错误检测方式）
### **4.3.2 Unicode**
**Unicode 是一种 16 位编码方式**，用于表示字母数字（alphanumeric）数据。
它可以表示多达 216=65536 种不同的符号。
每个字符使用 **16 位（2 字节）** 进行编码。
### **4.3.3 Odd and Even Parity Checking 奇偶检验**
在发送数据时，**在原始数据后面附加一个额外的校验位（Parity Bit）**：
- 这个校验位的值取决于信息位中“1”的个数。
**分为两种形式：**
**Even Parity（偶校验）**

> 如果数据中 1 的个数是偶数，就设置校验位为 0；
> 
> 如果是**奇数**，就设置为 1，使得**总的 1 的个数变成偶数**。
**Odd Parity（奇校验）**

> 如果数据中 1 的个数是奇数，就设置校验位为 0；
> 
> 如果是**偶数**，就设置为 1，使得**总的 1 的个数变成奇数**。
发送和接收双方**事先约定**使用奇校验或偶校验。
硬件在收到数据后：
- 会根据预期的校验规则**重新统计 1 的个数**。
- 如果不符合预期，就说明**数据中可能有一位被破坏（flipped）了**。
- 检查完之后，校验位会被移除（stripped）。
