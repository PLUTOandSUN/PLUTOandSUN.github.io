# 音频处理临考复习笔记

> [!info] 使用说明
> 这份笔记按你的过往课程笔记、`2425_EBU5408_A` 往年题解析、Block 4 revision slides 和 Block 1&2 revision exercises 整理。目标不是重新讲完整课程，而是在临考前帮你快速抓住：**核心知识点、核心公式、常见题型、答题模板、易错点**。

> [!summary] 最高优先级
> 如果时间非常有限，先保住这些题型：
> 1. **声波/弦振动计算**：$v=f\lambda$，两端固定弦基频 $\lambda_1=2L$。

> 3. **量化与 SQNR**：$2^n$、$\Delta V$、$Q_{max}$、$SQNR\approx6.02n+1.76$。
> 4. **文件大小/码率**：sample rate × bit depth × channels × duration。
> 5. **MIDI 消息解析**：status byte + note + velocity，channel 注意 0-based/1-based。
> 6. **Huffman coding**：建树、码长、平均 bits、压缩率。
> 7. **PCA/ICA 场景题**：为什么 ICA 适合 source separation，pipeline、限制、改进、评价。
> 8. **AI voice cloning / ethics**：误用、治理、水印、检测、对抗鲁棒性。

## 2. 核心公式总表

### 2.1 声波与弦振动

| 含义 | 公式 | 说明 |
|---|---|---|
| 波速关系 | $v=f\lambda$ | $v$：波速，$f$：频率，$\lambda$：波长 |
| 周期 | $T=1/f$ | 频率越高，周期越短 |
| 正弦波 | $y(t)=A\sin(2\pi ft+\theta)$ | $A$ 振幅，$\theta$ 相位 |
| 角频率 | $\omega=2\pi f$ | $y=A\sin(\omega t+\theta)$ |
| 两端固定弦基频波长 | $\lambda_1=2L$ | 基频时弦长等于半个波长 |
| 两端固定弦基频 | $f_1=\frac{v}{2L}$ | 弦越长，基频越低 |
| 第 $n$ 次谐波 | $f_n=nf_0$ | 第 2 谐波 $2f_0$，第 3 谐波 $3f_0$ |
| 八度 | $f\rightarrow 2f$ | 频率翻倍，音高升一个 octave |

> [!warning] 往年题坑点
> 两端固定弦的基频不要把 $L$ 当成 $\lambda$。正确是 $\lambda_1=2L$。

### 2.2 dB、SPL、SNR、动态范围

| 含义 | 公式 | 说明 |
|---|---|---|
| 声压级 | $dB_{SPL}=20\log_{10}\left(\frac{p}{p_0}\right)$ | $p_0=20\mu Pa=0.00002Pa$ |
| 从 dB 反推声压 | $p=p_0\times10^{dB/20}$ | 常用于 SPL 反算 Pa |
| 功率比 SNR | $SNR_{dB}=10\log_{10}\left(\frac{P_{signal}}{P_{noise}}\right)$ | 功率/能量比用 10 log |
| 幅度比 SNR | $SNR_{dB}=20\log_{10}\left(\frac{A_{signal}}{A_{noise}}\right)$ | 振幅/电压/声压比用 20 log |
| 动态范围 | $DR=20\log_{10}\left(\frac{max}{min}\right)$ | 最大可表示信号与最小可检测信号之比 |
| dB 到线性幅度增益 | $G=10^{dB/20}$ | +6 dB ≈ 2 倍，-6 dB ≈ 0.5 倍，+12 dB ≈ 4 倍 |

### 2.3 Sampling、Nyquist、Aliasing

| 含义 | 公式 | 说明 |
|---|---|---|
| Nyquist frequency | $f_N=\frac{f_s}{2}$ | 给定采样率下最高可无混叠表示的频率 |
| Nyquist rate | $f_s\ge2f_{max}$ | 为表示最高频率 $f_{max}$，采样率至少为其两倍 |
| alias frequency | $f_{alias}=|f-kf_s|$ | 选整数 $k$ 使结果落在 $0$ 到 $f_N$ 之间 |
| anti-aliasing | low-pass before sampling/downsampling | 采样或降采样前去除高于新 Nyquist 的频率 |

> [!example] 往年题模板
> $f_s=2000Hz$，所以 $f_N=1000Hz$。1500 Hz 和 2500 Hz 都高于 Nyquist，因此会 alias：
> - $|1500-2000|=500Hz$
> - $|2500-2000|=500Hz$

### 2.4 Quantisation、SQNR、Bit Depth

| 含义 | 公式 | 说明 |
|---|---|---|
| 量化级数 | $2^n$ | $n$ 是 bit depth |
| 量化步长 | $\Delta V=\frac{2V_{max}}{2^n}$ | 若范围是 $-V_{max}$ 到 $+V_{max}$ |
| 最大量化误差 | $Q_{max}=\frac{\Delta V}{2}$ | 最近量化值误差最多半个 step |
| 经验 SQNR | $SQNR\approx6.02n+1.76dB$ | 理想满幅正弦输入模型 |
| 简化动态范围 | $DR\approx6.02n dB$ | 每增加 1 bit 约增加 6 dB |
| 题目给定式 | $SQNR=20\log_{10}\left(\frac{V_{max}}{Q_{noise}}\right)$ | 注意 $Q_{noise}$ 是最大误差还是 RMS 噪声 |

> [!important] 1.76 dB 怎么解释
> $6.02n+1.76$ 中的 1.76 dB 来自理想均匀量化噪声的 RMS 模型和满幅正弦信号 RMS/峰值之间的常数项，不是随便加的修正。

### 2.5 文件大小、码率、压缩比

| 含义 | 公式 | 说明 |
|---|---|---|
| PCM bitrate | $bitrate=f_s\times bit\ depth\times channels$ | 单位通常是 bits/s |
| 每秒字节数 | $bytes/s=\frac{f_s\times bit\ depth\times channels}{8}$ | bits 转 bytes 除以 8 |
| 文件大小 | $size=bitrate\times duration$ | 若 bitrate 是 bits/s，结果是 bits |
| MP3 大小 | $size=\frac{bitrate(bits/s)\times duration(s)}{8}$ | kbps 是 kilobits/s，不是 kB/s |
| 压缩比 | $ratio=\frac{original\ size}{compressed\ size}$ | 例如 11.52 MB / 0.96 MB = 12:1 |

> [!example] 高频题
> 48 kHz / 16-bit / stereo / 60s WAV：
> $$48000\times16\times2\times60/8=11,520,000\ bytes\approx11.52MB$$
> 128 kbps MP3 / 60s：
> $$128000\times60/8=960,000\ bytes\approx0.96MB$$

### 2.6 Huffman / Entropy Coding

| 含义 | 公式/规则 | 说明 |
|---|---|---|
| 平均码长 | $L_{avg}=\sum p_i l_i$ | $p_i$ 是概率，$l_i$ 是 code length |
| 节省 bits | $saving=fixed\ length-L_{avg}$ | 每个 symbol 平均节省 |
| 节省比例 | $\frac{fixed-L_{avg}}{fixed}$ | 可写成百分比 |
| 压缩比 | $\frac{fixed}{L_{avg}}$ | 例如 3/2.1≈1.43:1 |
| Shannon entropy | $H=-\sum p_i\log_2p_i$ | 理论平均最短码长下限 |
| Huffman 原则 | 高频短码，低频长码 | prefix-free，code 不唯一但平均码长一致 |

### 2.7 Real-Time Audio Latency

| 含义 | 公式 | 说明 |
|---|---|---|
| 单向 buffer latency | $Latency(ms)=\frac{BufferSize}{SampleRate}\times1000$ | buffer 越小 latency 越低 |
| round-trip latency | $RoundTrip=\frac{BufferSize}{SampleRate}\times1000\times2$ | 近似 input + output |

例子：

- 256 samples at 48 kHz round-trip：$256/48000\times1000\times2\approx10.7ms$。
- 128 samples at 48 kHz round-trip：$128/48000\times1000\times2\approx5.3ms$。

### 2.8 音频质量评价指标

| 指标 | 公式/含义 | 用途 |
|---|---|---|
| SNR | $10\log_{10}(P_s/P_n)$ | 噪声相对信号大小 |
| THD | $THD(\%)=\frac{RMS\ harmonics}{RMS\ fundamental}\times100$ | harmonic distortion |
| IMD | intermodulation distortion | 多频输入下的新频率成分失真 |
| MSE | $MSE=\frac{1}{N}\sum(original[i]-processed[i])^2$ | 与 reference 的 sample-level 差异 |
| RMSE | $RMSE=\sqrt{MSE}$ | MSE 的平方根 |
| PSNR | $20\log_{10}\left(\frac{MAX_{signal}}{RMS_{error}}\right)$ | 与 reference 的峰值信噪比 |
| PEAQ | perceptual audio quality | music/general audio perceptual quality |
| POLQA / PESQ | speech perceptual quality | 语音通信/增强 |
| ViSQOL | speech/audio perceptual quality | 对 time misalignment 较鲁棒 |
| SDR | signal-to-distortion ratio | source separation / denoising headline metric |
| STOI | speech intelligibility | 语音可懂度 |
| Amari Error | ICA/BSS 矩阵分离误差 | 越接近 0 越好 |

### 2.9 机器学习评价指标

| 指标 | 公式 | 适用 |
|---|---|---|
| Accuracy | $\frac{TP+TN}{TP+TN+FP+FN}$ | 类别平衡时直观 |
| Precision | $\frac{TP}{TP+FP}$ | 预测为正的有多少是真的 |
| Recall | $\frac{TP}{TP+FN}$ | 真实正样本找回多少 |
| F1 | $2\frac{Precision\times Recall}{Precision+Recall}$ | precision/recall 折中 |
| EER | false acceptance = false rejection 时错误率 | speaker verification |

## 3. Block 1 核心知识：声波、听觉、数字化

### 3.1 声音与声波

来源：[[课程笔记/音频处理/Block 1/Block 1 - PPT 2：Sound Waves.md]]

- 声音来自物体振动，是在介质中传播的 pressure wave。
- 空气中的声音是 longitudinal wave，介质粒子沿传播方向前后振动。
- 频率 $f$ 决定主观 pitch；振幅 $A$ 与响度/强度有关；相位影响波形叠加。
- 复杂声音可以看成多个正弦成分叠加，这是 Fourier analysis 的基础。
- Spectrum 显示频率成分；spectrogram 显示频率随时间变化。

### 3.2 Resonance / Harmonics / Standing Wave

- 两端固定弦只能形成满足边界条件的 standing waves。
- 基频是最低自然振动频率。
- Harmonics 是基频的整数倍：$f_n=nf_0$。
- 弦长增加，基频降低；弦长减小，基频升高。

### 3.3 Psychoacoustics：人耳不是线性仪器

来源：[[课程笔记/音频处理/Block 1/Block 1 - PPT 3：Sound Perception.md]]

必须掌握：

- threshold of hearing：人耳能听到的最低 SPL，随频率变化。
- equal-loudness curves：相同 SPL 不一定听起来一样响。
- critical bands：内耳按频率带宽处理声音；临界带内的声音更容易互相掩蔽。
- frequency masking：强声音提高邻近频率的听阈，使弱声音听不见。
- temporal masking：强声音前后短时间内会掩蔽较弱声音。

> [!important] Masking 和压缩的关系
> MP3 等有损压缩利用 psychoacoustic model：被强声音掩蔽、听不明显的频率成分可以删除或用更少 bits 表示。

### 3.4 Masking 题答题模板

```text
1. Identify the masker frequency and SPL.
2. Use critical band table or bandwidth to estimate distance in critical bands.
3. Apply the stated decrease, e.g. 15 dB per critical band.
4. Masking threshold = masker SPL - decrease × number of bands.
5. In the graph: label frequency axis, SPL axis, original hearing threshold, masker, raised threshold.
```

### 3.5 Digitisation：采样 + 量化 + 编码

来源：[[课程笔记/音频处理/Block 1/Block 1 - PPT 4：Digitisation of Sound.md]]

- Sampling：时间离散化，每秒取 $f_s$ 个样本。
- Quantisation：幅度离散化，把连续幅度映射到有限级别。
- Encoding：把样本按格式存储/传输。
- PCM：最常见的未压缩数字音频表示。
- WAV：常见容器，通常存储 PCM data + header + metadata。

### 3.6 Sampling 与 aliasing 必背解释

> If a frequency component is above the Nyquist frequency, it cannot be represented correctly after sampling and will fold back into a lower frequency. This is aliasing. To prevent it, an anti-aliasing low-pass filter should remove frequencies above the Nyquist limit before sampling or downsampling.

### 3.7 Quantisation 必背解释

- bit depth 越高，量化级数越多，量化间隔越小，量化噪声越低。
- 每增加 1 bit，理想动态范围/SQNR 约提升 6 dB。
- Dithering 是加入低电平噪声，把 correlated quantisation error 变成更自然的噪声。
- Noise shaping 把噪声推到人耳较不敏感的频段。

## 4. Block 2 核心知识：MIDI、合成、音乐与语音

### 4.1 MIDI 不是音频

来源：[[课程笔记/音频处理/Block 2/Block 2 - PPT 1：MIDI and Sound Synthesis.md]]

MIDI 是控制数据，不是声音波形。它告诉 synthesiser：

- 什么时候开始/停止某个 note；
- 使用哪个 channel；
- note number 是多少；
- velocity 是多少；
- program/patch/controller 如何改变。

### 4.2 MIDI message 结构

Channel voice message 通常是：

```text
status byte + data byte 1 + data byte 2
```

Note-On：

```text
0x9n note velocity
```

Note-Off：

```text
0x8n note velocity
```

其中：

- status byte 高 nibble 表示 message type；
- 低 nibble 表示 channel index，0-15；
- human-readable channel 通常是 index + 1。

> [!example] 往年题例子
> `0x94 0x2D 0x1E`：
> - `0x9` = Note On；
> - `0x4` = encoded channel 4 = displayed channel 5；
> - `0x2D = 45`；
> - `0x1E = 30`。

### 4.3 Hex 转 decimal 快速方法

| Hex | Decimal |
|---|---:|
| `0x3C` | $3\times16+12=60$ |
| `0x64` | $6\times16+4=100$ |
| `0x2D` | $2\times16+13=45$ |
| `0x1E` | $1\times16+14=30$ |
| `0x7F` | 127 |

### 4.4 ADSR Envelope

ADSR 是控制声音随时间变化的 envelope：

| 阶段 | 含义 | 易错点 |
|---|---|---|
| Attack | 从 0 到 peak 的时间 | 不是音量值，是时间 |
| Decay | 从 peak 降到 sustain 的时间 | 也是时间 |
| Sustain | 按键保持时的稳定 level | 是 level，不是 time |
| Release | 松键后衰减到 0 的时间 | 决定尾音长短 |

### 4.5 Sound synthesis 必背

- Oscillator：产生 sine / square / sawtooth / triangle / noise。
- Filter：改变频率内容，例如 low-pass 去掉高频谐波。
- Amplifier：控制整体幅度。
- Envelope：控制动态变化。
- LFO/modulation：产生 vibrato、tremolo 等变化。

Subtractive synthesis signal flow：

```text
oscillator → filter → amplifier/envelope → effects → output
```

### 4.6 AM vs FM

| 类型 | 含义 | 听感/用途 |
|---|---|---|
| AM | amplitude modulation，调制振幅 | tremolo、音量周期变化、sidebands |
| FM | frequency modulation，调制频率 | vibrato、复杂金属/电钢音色 |

### 4.7 Music vs Speech

来源：[[课程笔记/音频处理/Block 2/Block 2 - PPT 2：Music and Speech.md]]

| 对比 | Speech | Music |
|---|---|---|
| Pitch | 与说话人、语调、情绪有关 | 通常更稳定、受音阶/和声约束 |
| Timing | 受 syllable、stress、语言节奏影响 | 受 tempo、beat、meter 影响 |
| Harmonics | formants 对语音辨识重要 | harmonic structure 与乐器音色重要 |
| Dynamic range | 通常较受控 | 可非常大，尤其古典/现场音乐 |
| Spectrogram | vowel formants、fricative noise、plosive bursts | harmonics、onsets、rhythmic patterns |

### 4.8 Voiced / Unvoiced / Formants

- Voiced sounds：声带振动，有 pitch、周期性，例如 vowels、/m/、/z/、/l/。
- Unvoiced sounds：声带不振动，噪声性强，例如 /s/、/t/、/k/、/f/。
- Formants：声道共振峰，用于区分 vowels。
- Vowel spectrogram：清晰 formant bands。
- Unvoiced fricative：高频噪声，缺少明显 pitch。
- Voiced plosive：短暂爆破 + 可能有 voicing bar。

### 4.9 ASR / Speaker Recognition

ASR pipeline：

```text
audio input → preprocessing → feature extraction (STFT/MFCC) → acoustic model → language model → decoding → text
```

Speaker recognition：

| 任务 | 含义 | 答题关键词 |
|---|---|---|
| Speaker verification | 判断“是不是某人” | one-to-one，claimed identity，accept/reject |
| Speaker identification | 判断“是谁” | one-to-many，从数据库中找最匹配 speaker |

## 5. Block 3 核心知识：压缩、PCA/ICA、滤波

### 5.1 Compression：为什么能压缩？

来源：[[课程笔记/音频处理/Block 3/Block 3 - PPT 1：Compression and Decompression.md]]

音频压缩利用：

- temporal redundancy：相邻 samples 相似；
- statistical redundancy：某些符号/残差出现更频繁；
- psychoacoustic irrelevance：有些成分人耳听不明显。

### 5.2 Lossless vs Lossy

| 对比 | Lossless | Lossy |
|---|---|---|
| 能否完全恢复 | 可以 | 不可以 |
| 压缩率 | 较低 | 较高 |
| 典型格式 | FLAC、ALAC | MP3、AAC、Opus |
| 原理 | prediction + residual + entropy coding | masking + transform + quantisation |
| 风险 | 压缩率有限 | artifacts、音质损失 |

### 5.3 FLAC / Residual / Huffman

Lossless audio compression 常见流程：

```text
original samples → prediction → residuals → entropy coding → compressed bitstream
```

Residual 是：

```text
residual = actual sample - predicted sample
```

如果 predictor 好，residual 接近 0，而 0 或小数值出现频率高，适合 Huffman / Rice coding。

### 5.4 Huffman coding 固定步骤

```text
1. 按频率从小到大排序。
2. 每次合并两个最小节点。
3. 重复直到总频率为 100%。
4. 给左右分支分配 0/1。
5. 从根到叶读出每个 code。
6. 用 L_avg = Σp_i l_i 算平均码长。
7. 与 fixed-length code 比较，算节省比例和压缩比。
```

> [!warning] Huffman code 不唯一
> 左右分支 0/1 可以互换，所以 codeword 可能不同；但只要树正确、prefix-free、平均码长正确，就可以得分。

### 5.5 MP3 / Lossy Compression Pipeline

MP3 的核心流程：

```text
frame splitting → windowing → MDCT/filterbank → psychoacoustic model → quantisation/bit allocation → entropy coding → bitstream
```

必须会解释：

- frame/window：把长音频切成短时片段。
- MDCT：把时域变换到频域，便于能量压缩和心理声学处理。
- psychoacoustic model：判断哪些频率被 masking。
- quantisation：对不敏感频段更粗量化。
- entropy coding：进一步减少统计冗余。

### 5.6 PCA：降维/去噪，不等于源分离

来源：[[课程笔记/音频处理/Block 3/Block 3 - PPT 2：PCA and ICA.md]]

PCA 核心：

- Principal Component Analysis。
- 找最大方差方向。
- 新坐标轴彼此正交、uncorrelated。
- 常用于 dimensionality reduction、denoising、whitening。
- 依赖 second-order statistics：variance / covariance。
- PCA 前要 data centering：$X_c=X-\mu$。

PCA denoising 逻辑：

```text
frame audio → center data → PCA → keep principal components → reconstruct → overlap-add
```

选择 components：

- explained variance ratio；
- elbow method；
- MSE / SNR / listening test；
- 不要只看数值，重构听感也重要。

### 5.7 ICA：独立成分与盲源分离

ICA 核心：

- Independent Component Analysis。
- 用于 Blind Source Separation。
- 假设源信号 statistically independent。
- 目标是从 mixed observations 中估计 source components。
- 数学模型：$X=AS$，估计 $W$，使 $\hat{S}=WX$。

ICA 为什么适合 cocktail party problem：

> Because speech, vehicle noise and background chatter can be treated as different source components. ICA attempts to separate statistically independent sources from mixed recordings, while PCA mainly decorrelates data and reduces dimensionality.

### 5.8 PCA vs ICA 必背对比

| 对比 | PCA | ICA |
|---|---|---|
| 目标 | 降维、去相关、保留最大方差 | 分离统计独立源 |
| 统计依据 | second-order statistics | higher-order statistics / independence |
| 输出关系 | components uncorrelated | components as independent as possible |
| 常见用途 | denoising、compression、whitening | BSS、cocktail party、source separation |
| 局限 | 不保证 unmix sources | 需要独立性假设，受通道数/混响影响 |

### 5.9 ICA 题标准 pipeline

```text
1. Audio loading and inspection
   - check sample rate, channels, clipping, noise, duration.

2. Pre-processing
   - resample, mono/stereo handling, normalise, remove DC, high-pass, notch, trim silence.

3. Time-frequency representation
   - STFT / spectrogram if useful; choose frame length, hop size, window.

4. Whitening / centering
   - center data and optionally whiten to improve ICA stability.

5. ICA separation
   - choose n_components; run FastICA or similar.

6. Component selection
   - identify target speech component using listening, spectrogram, speech features, energy, intelligibility.

7. Reconstruction
   - inverse transform / ISTFT; restore time-domain audio.

8. Post-processing
   - Wiener filtering, spectral subtraction, EQ, band-pass, de-reverb, normalisation.

9. Evaluation
   - SNR, SDR, PESQ, STOI, spectrogram inspection, listening tests.

10. Limitations and improvements
   - discuss assumptions, channel/source mismatch, non-stationary noise, reverberation, artifacts.
```

### 5.10 ICA 限制与改进

限制：

- 源之间不完全 independent；
- 目标语音和 crowd chatter 都是 speech，频谱相似；
- 非平稳车辆噪声和人群噪声随时间变化；
- reverberation 破坏简单 mixing model；
- 源数可能多于麦克风通道；
- scaling / permutation ambiguity；
- 分离后可能有 artifacts。

改进：

- pre-filtering：high-pass / notch / band-pass；
- VAD：只处理 speech-active segments；
- beamforming：多麦克风时利用空间信息；
- Wiener filtering / spectral subtraction：后处理残余噪声；
- NMF / deep learning speech enhancement：处理复杂非平稳噪声；
- de-reverberation；
- parameter tuning；
- subjective + objective evaluation。

### 5.11 Filtering / EQ 核心

来源：[[课程笔记/音频处理/Block 3/Block 3 - PPT 3：Audio Quality, Noise, and Digital Filtering.md]]；[[课程笔记/音频处理/Block 4/Block 4 - PPT 1：Audio Quality, Noise, and Digital Filtering II.md]]

| 滤波器 | 作用 | 典型用途 |
|---|---|---|
| Low-pass | 保留低频，削弱高频 | 去 hiss，高频噪声 |
| High-pass | 保留高频，削弱低频 | 去 rumble、DC offset，改善 speech clarity |
| Band-pass | 保留中间频段 | 提取语音/目标频带 |
| Band-stop / Notch | 去除窄频段 | 50/60 Hz hum |
| Shelving | 提升/削弱某一侧整体频段 | bass/treble tone shaping |
| Peaking | 提升/削弱中心频率附近 | 去 resonance / presence boost |

### 5.12 FIR vs IIR

| 对比 | FIR | IIR |
|---|---|---|
| impulse response | finite | infinite due to feedback |
| 稳定性 | 通常更容易保证 | 需要注意稳定性 |
| 相位 | 可 linear phase | 可能 phase distortion |
| 延迟 | 长 FIR 延迟较高 | 通常低延迟 |
| 计算效率 | 高阶时成本高 | 少量系数即可实现陡峭响应 |
| 适合 | offline、高质量、线性相位 | real-time EQ、低延迟系统 |

> [!important] Real-time EQ 为什么常用 IIR
> IIR 计算效率高、延迟低、适合实时参数更新。FIR 可以更精确和线性相位，但长 FIR 会带来 latency 和计算压力。

## 6. Block 4 核心知识：实时音频、ML、AI Ethics、Forensics

### 6.1 Real-Time Audio Processing

来源：[[课程笔记/音频处理/Block 4/Block 4 - PPT 2：Real-Time Audio Processing, Machine Learning, Ethics and Forensics.md]]

实时音频处理定义：

```text
Audio is processed as it arrives.
Processing must finish before the next buffer arrives.
```

核心约束：

- low latency；
- stable processing time；
- CPU/RAM/audio interface constraints；
- no glitches/dropouts；
- causal processing。

Buffer trade-off：

| Buffer size | 优点 | 缺点 |
|---|---|---|
| small | latency 低，响应快 | CPU 压力大，容易 underrun/glitch |
| large | 稳定，CPU 有更多时间 | latency 高，演奏/通话不自然 |

### 6.2 Online vs Batch

| 对比 | Online / Real-time | Batch / Offline |
|---|---|---|
| 处理方式 | sample/block arrives 时立即处理 | 整段或大块音频离线处理 |
| 要求 | causal、low latency、stable | 可复杂、可 non-causal、可看未来 samples |
| 例子 | live performance、voice chat、real-time effects | mastering、dataset feature extraction、restoration |

### 6.3 Audio ML Features

| 特征 | 类型 | 含义/用途 |
|---|---|---|
| ZCR | time-domain | 过零率，高频/噪声/清浊音 |
| RMS energy | time-domain | 响度、silence detection、onset |
| Spectral centroid | frequency-domain | 频谱重心，bright/dark |
| Spectral roll-off | frequency-domain | 能量累计到 85%/95% 的频率，带宽/高频含量 |
| MFCC | perceptual cepstral | 语音/音色，speech/speaker recognition |
| Chroma | music feature | 12 个 pitch classes，和弦/调性 |
| Spectral contrast | texture | peaks vs valleys，音色 texture |

Audio ML pipeline：

```text
data collection & labelling → preprocessing → feature extraction → model training → evaluation → deployment
```

### 6.4 为什么 raw audio 通常需要 feature extraction？

- raw waveform 维度高；
- temporal dependency 复杂；
- 冗余多；
- 数据量大、训练慢；
- compact features 更容易让模型学习任务相关信息。

### 6.5 AI Audio Ethics / Voice Cloning

AI voice cloning 的正面用途：

- accessibility；
- voice banking for medical patients；
- personalised assistants；
- dubbing with consent；
- content creation。

误用风险：

- impersonation；
- fraud；
- fake CEO transfer requests；
- misinformation / disinformation；
- political manipulation；
- blackmail；
- social engineering；
- reputational harm。

公司防滥用措施：

- strict usage policy；
- identity verification；
- explicit consent from voice owners；
- watermarking / unique identifiers；
- logging and monitoring；
- rate limits；
- abuse reporting；
- transparency and audits。

对抗攻击鲁棒性：

- adversarial training；
- regularisation：dropout、weight decay、noise injection；
- multi-modal / hybrid detection：pitch、timbre、prosody、linguistic style、metadata、水印；
- watermarking and integrity checks；
- continuous monitoring and retraining。

### 6.6 Audio Forensics

Forensic audio 的目标不是“变好听”，而是：

- authenticate recordings；
- enhance intelligibility；
- preserve evidence integrity；
- identify speakers；
- analyse recording conditions；
- document reproducible processing。

Restoration vs Forensics：

| 对比 | Audio restoration | Forensic audio |
|---|---|---|
| 目标 | 听感更好 | 证据真实、可解释、可复现 |
| 处理强度 | 可更积极 | minimal and documented |
| 风险 | artifacts | 改变证据含义、法律不可采 |
| 输出 | 清晰/好听音频 | 原始文件、hash、处理日志、分析报告 |

Forensic workflow：

```text
preserve original → forensic copy → hash → metadata inspection → spectrogram/ENF/phase analysis → minimal enhancement → report with parameters and limitations
```

常见技术：

- metadata inspection；
- ENF analysis；
- spectrogram analysis；
- phase discontinuity detection；
- noise floor consistency；
- speaker recognition；
- chain of custody。

## 8. 英文答题句型速记

### 8.1 Sampling / aliasing

> The Nyquist frequency is half of the sampling rate. Any frequency component above this limit will be folded back into the lower frequency range, causing aliasing.

> An anti-aliasing low-pass filter should be applied before sampling or downsampling to remove components above the Nyquist frequency.

### 8.2 Quantisation

> Increasing bit depth increases the number of quantisation levels, reduces the quantisation interval, and therefore reduces quantisation noise.

> The 1.76 dB offset comes from the RMS relationship between a full-scale sine wave and uniformly distributed quantisation noise.

### 8.3 Masking

> A loud tone raises the hearing threshold of nearby frequencies, making quieter components within neighbouring critical bands inaudible.

> Psychoacoustic compression exploits masking by allocating fewer bits to components that are less perceptible to human hearing.

### 8.4 MIDI

> MIDI is not audio; it is event-based control data that instructs a synthesiser which note to play, on which channel, and with what velocity.

### 8.5 PCA / ICA

> PCA mainly reduces dimensionality and decorrelates data by retaining directions of maximum variance.

> ICA is more suitable for source separation because it aims to recover statistically independent components from mixed observations.

### 8.6 Huffman coding

> Huffman coding assigns shorter codes to more frequent symbols and longer codes to less frequent symbols, reducing the average number of bits per symbol while remaining prefix-free.

### 8.7 Real-time audio

> Smaller buffers reduce latency but increase CPU pressure and the risk of buffer underruns or glitches.

### 8.8 Forensics

> Forensic enhancement should be minimal, documented, and reproducible so that the integrity and evidential meaning of the recording are preserved.

### 8.9 AI voice cloning

> Voice cloning can support accessibility and medical applications, but it can also be misused for impersonation, fraud, misinformation and social engineering.

## 9. 往年题专项速刷

### 9.1 Q1(a) 弦振动

必写步骤：

1. 基频：$\lambda=2L$。
2. 波速：$v=f\lambda$。
3. 新弦长：$f'=\frac{v}{2L'}$ 或 $f'=f\frac{L}{L'}$。
4. 解释：弦变长，频率降低，pitch 下降。

### 9.2 Q1(b) Sampling / aliasing

必写步骤：

1. $f_N=f_s/2$。
2. 大于 $f_N$ 的频率会 alias。
3. 用 $f_{alias}=|f-kf_s|$ 折叠。
4. 画 reconstructed spectrum。

### 9.3 Q1(c) Quantisation / SQNR

必写步骤：

1. 量化级数 $2^n$。
2. 如果范围是 $-V_{max}$ 到 $+V_{max}$，总范围是 $2V_{max}$。
3. $\Delta V=2V_{max}/2^n$。
4. $Q_{max}=\Delta V/2$。
5. 代入 SQNR 公式。
6. 若比较 $6.02n+1.76$，解释 RMS 模型和 1.76 dB。

### 9.4 Q2(a) Critical band / masking

必写步骤：

1. 找 masker frequency 和 SPL。
2. 根据 critical band table 判断两个 tone 距离几个 band。
3. 每个 band 衰减多少 dB，计算 threshold。
4. 画 threshold curve。
5. 说明 masking effect 随距离增大而减弱。

### 9.5 Q2(b) MIDI

必写步骤：

1. 拆 status byte 高 nibble / 低 nibble。
2. 高 nibble 判断 Note On / Note Off。
3. 低 nibble 算 channel index，再 +1 得 displayed channel。
4. data byte 1 是 note number。
5. data byte 2 是 velocity。

### 9.6 Q2(c) ADSR

必写关键词：

- Attack：rise to peak。
- Decay：fall to sustain。
- Sustain：held level。
- Release：fade after key release。

> [!warning] 易错
> Sustain 是 level，不是 duration。

### 9.7 Q2(d) Speaker verification / identification

标准答案：

- 相同点：都使用 speaker-specific features，例如 MFCC、pitch、formants、embeddings。
- Verification：one-to-one，判断是否为 claimed identity，输出 accept/reject。
- Identification：one-to-many，在 enrolled speakers 中找最匹配者。

### 9.8 Q3 ICA 场景题

标准结构：

1. 城市场景有 vehicle noise、crowd chatter、overlapping speech。
2. 简单滤波不足，因为频率重叠且噪声非平稳。
3. ICA 更适合，因为它分离 independent components。
4. PCA 可以降维/去噪，但不保证 unmix sources。
5. Pipeline：preprocess → STFT → whitening → ICA → select target component → inverse transform → postprocess → evaluate。
6. 选择 component 数：从源数量估计开始，例如 target speech + vehicle noise + crowd chatter ≈ 3，结合 PCA variance、SNR/SDR/PESQ/STOI、spectrogram、listening tests 调整。
7. 限制：独立性、通道数、混响、相似语音、非平稳噪声、artifacts。
8. 改进：filtering、Wiener、spectral subtraction、beamforming、NMF、deep learning。

### 9.9 Q4(a) 文件大小

标准结构：

1. 写出 sampling rate、bit depth、channels、duration。
2. 每个 sample 每 channel 字节数 = bit depth / 8。
3. stereo 乘 2。
4. 每秒 bytes = sample rate × bytes per frame。
5. 乘 duration。
6. 转 MB / MiB。
7. MP3 用 bitrate × duration / 8。

### 9.10 Q4(b) Huffman

标准结构：

1. 按 frequency 排序。
2. 合并两个最小节点。
3. 画 tree。
4. 读出 code。
5. 算 $L_{avg}=\sum p_i l_i$。
6. 与 fixed length 比较。
7. 解释高频短码所以压缩。

### 9.11 Revision slides AI voice cloning 题

标准结构：

- Misuse：impersonation/fraud、misinformation、blackmail/social engineering。
- Company safeguards：policy、verification、consent、watermarking、monitoring。
- Adversarial robustness：adversarial training、regularisation、hybrid detection、watermark/integrity checks、continuous updates。

## 10. 最容易失分的地方

1. **弦题**：把 $L$ 当作 $\lambda$；正确是 $\lambda=2L$。
2. **Nyquist**：混淆 Nyquist rate 和 Nyquist frequency。
3. **Aliasing**：只判断 alias，不计算 alias 后频率。
4. **量化**：忘记电压范围是 $2V_{max}$。
5. **SQNR**：不知道 1.76 dB 的解释。
6. **Masking**：只看 Hz 差，不联系 critical band。
7. **MIDI**：channel index 忘记 +1；kbps/hex conversion 粗心。
8. **ADSR**：把 sustain 当成时间。
9. **Speaker recognition**：verification 和 identification 不写 one-to-one / one-to-many。
10. **ICA**：只写 “use ICA”，没有 pipeline、局限、评价。
11. **文件大小**：stereo 忘乘 2；bits 转 bytes 忘除 8；kbps 当 kB/s。
12. **Huffman**：code 不唯一但 tree/平均码长必须正确；忘记 weighted average。
13. **伦理题**：泛泛写 “dangerous”，没有具体 harms 和 safeguards。
14. **Forensics**：过度处理，忘记 chain of custody 和 hash。
